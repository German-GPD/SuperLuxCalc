# SuperLuxCalc Collection

This repository contains calculator implementations in multiple languages.

Files:
- `index.html` — HTML/CSS/JS calculator in one file
- `superluxcalc.py` — Python CLI calculator
- `superluxcalc.js` — JavaScript CLI calculator
- `superluxcalc.c` — C console calculator
- `superluxcalc.cpp` — C++ calculator with expression parser
- `superluxcalc.go` — Go calculator
- `superluxcalc.php` — PHP CLI calculator
- `superluxcalc.pas` — Pascal calculator

## Quick start
- HTML: open `index.html` in any browser
- Python: `python3 superluxcalc.py`
- JavaScript: `node superluxcalc.js`
- C: `gcc superluxcalc.c -lm -o superluxcalc && ./superluxcalc`
- C++: `g++ superluxcalc.cpp -O2 -o superluxcalc -lm && ./superluxcalc`
- Go: `go run superluxcalc.go`
- PHP: `php superluxcalc.php`
- Pascal: `fpc superluxcalc.pas && ./superluxcalc`

These calculators are intended as fun, powerful examples with a stylish interface or console-based functionality.
